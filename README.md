# Allo Reservation System

A simple inventory reservation system built using Next.js, Prisma, and Supabase.

## Features

- Product listing
- Reserve product functionality
- Backend API using Next.js
- PostgreSQL database with Supabase
- Prisma ORM integration

## Tech Stack

- Next.js
- TypeScript
- Prisma
- Supabase
- PostgreSQL

## Run Locally

```bash
npm install
npm run dev
```

Open:

http://localhost:3000
